## 🧐 About <a name = "about"></a>

Simple integration to extract data using the Chess.com API and upload it to a PostgreSQL database. After configuring the database, you can consume the data in any preferred dashboard platform.

## 🏁 Getting Started <a name = "getting_started"></a>

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes. 

### Installing

Simply clone the repo and pip install the requirements:

```
git clone https://github.com/jvfonseca1/Chesslytics.git
```
```
pip install -r ./requirements.txt
```

## 🎈 Usage <a name="usage"></a>

This integration fetches basic data from the Chess.com API and uploads it to a database of your choice. You can then use your preferred tools to create dashboards and analyze your games.
